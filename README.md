# the-sfm trader

powered by M.ALQ

تطبيق ويب عربي يعرض توصيات آلية للأسواق: فوركس، الكويت، السعودية، الخليج، السوق الأمريكي، أوروبا، آسيا، وكل العالم.

## التشغيل

```powershell
cd "C:\Users\User\the-sfm trader"
npm start
```

ثم افتح:

```text
http://localhost:4173
```

## تشغيل الإنتاج الآمن

يتطلب الإنتاج Node.js 22 وHTTPS وهوية مستخدم لكل بيانات الصفقات والتنبيهات والأوامر الصوتية. عرّف الأسرار في منصة الاستضافة ولا تحفظها في Git:

```text
NODE_ENV=production
SFM_AUTH_TOKENS={"رمز-عشوائي-طويل-لا-يقل-عن-24-حرفا":"user-1"}
SFM_ALLOWED_ORIGINS=https://trader.the-sfm.com
SFM_DATA_DIR=/مسار/تخزين/دائم
```

بعد الدخول، يوضع رمز الوصول في الإعدادات > الأمان. الخادم يخزن حالة كل مستخدم في نطاق مستقل ويستخدم كتابة ذرية. التخزين المحلي الافتراضي مناسب لخادم واحد فقط؛ عند التوسع الأفقي يجب استبدال `src/fileStore.mjs` بمستودع قاعدة بيانات يطبق القيود والعزل نفسه.

## التحقق

```text
npm ci
npm run verify
npm start
npm run smoke
```

يشمل `npm run verify` اختبار تكامل Production يشغل خادماً مؤقتاً ويتحقق من المصادقة وCORS ورؤوس الأمان وETag والإغلاق الآمن. لا يحتاج الاختبار إلى أسرار حقيقية أو اتصال بمزود بيانات خارجي.

يعمل CI تلقائيا على كل Pull Request ويشغل فحص الصياغة واختبارات الوحدة وتدقيق الاعتماديات. نقطة فحص الخدمة: `/api/health`.

## البنية

- `server.mjs`: طبقة HTTP والتوجيه والتجميع الحالية.
- `src/security.mjs`: المصادقة، CORS، حدود الطلبات ورؤوس الأمان.
- `src/fileStore.mjs`: تخزين ذري ومعزول حسب المستخدم وقابل للاستبدال بقاعدة بيانات.
- `src/dataProviders.mjs`: مزودو بيانات السوق وسياسة fallback.
- `src/analysis.mjs`: التحليل الفني وإنشاء التوصيات.
- `public/`: واجهة الويب وPWA.
- `tests/`: اختبارات الأمن وعزل التخزين.

## قواعد صحة البيانات

- لا تعرض الواجهة أخبارا ثابتة أو وهمية على أنها حية.
- يجب إظهار المزود ووقت آخر تحديث وحالة البيانات المتأخرة أو غير المتاحة.
- التوصيات تعليمية وليست أوامر تنفيذ، وتتحول إلى انتظار عند إغلاق جلسة التنفيذ.
- لا تشارك بيانات الصفقات أو التنبيهات بين المستخدمين.

## ملاحظات مهمة

- التوصيات تعليمية وليست نصيحة مالية.
- الواجهة تطلب تحديثا كل ثانية، لكن تغير السعر الحقيقي يعتمد على السوق ومزود البيانات.
- بيانات الأسهم تأتي من Yahoo Finance عبر endpoint عام، لذلك قد تكون بعض أسواق الخليج ناقصة أو متأخرة.
- إذا كان المنفذ 4173 مشغولا، يحاول السيرفر تشغيل نفسه على المنفذ التالي مثل 4174 ويطبع الرابط في PowerShell.
- الواجهة تحتوي على خلفية حركة أسواق، شريط أسعار متحرك، بحث، فلترة، فرز، ملخص أفضل فرصة، ورسوم مصغرة لكل سهم.
- عند اختيار السوق الأمريكي تظهر خانة خاصة لتوقعات الصعود خلال شهر، شهرين، و3 شهور، مع هدف السعر مثل "الصعود إلى 12.00 USD خلال شهرين".
- في بطاقات السوق الأمريكي يظهر وسم "مطابق للشريعة" تحت شارة شراء/بيع للأسهم المصنفة محليا كمطابقة، ويجب تحديث التصنيف دوريا من مزود فحص شرعي موثوق.
- تم تجهيز تنبيهات ذكية: شراء + مطابق للشريعة + ثقة 70% أو أكثر.
- تم تجهيز فلتر شرعي داخل التوصيات: كل التصنيفات، مطابق، غير مطابق، مختلف عليه.
- كل بطاقة تعرض مؤشر مخاطرة ونتيجة اختبار خلفي Backtest مبسط على آخر بيانات متاحة.
- يمكن تبديل مزود البيانات عبر متغيرات البيئة الموضحة في `.env.example`: Yahoo افتراضي، أو Finnhub/Alpha Vantage عند توفر API key.
- لإضافة رموز جديدة، عدل ملف:

```text
C:\Users\User\the-sfm trader\src\markets.mjs
```
